# My Data Science Internship Experience at Oasis Infobyte

## Introduction

This blog documents my journey as a **Data Science Intern at Oasis Infobyte**, where I gained hands-on experience working with real-world datasets, applying machine learning techniques, and strengthening my analytical mindset. The internship served as a practical bridge between theoretical learning and industry-level problem solving.

---

## About Oasis Infobyte

Oasis Infobyte is a technology-driven organization focused on empowering students and professionals through skill-based internships and projects. The company emphasizes practical exposure, self-learning, and project-oriented growth, especially in domains like **Data Science, Web Development, and Software Engineering**.

---

## Internship Overview

* **Role:** Data Science Intern
* **Organization:** Oasis Infobyte
* **Mode:** Online (Remote)
* **Duration:** 1 Month
* **Focus Areas:** Data Analysis, Visualization, Machine Learning

During this one-month online internship, I worked on multiple real-world datasets and end-to-end data science projects. Each task was designed to strengthen my understanding of data preprocessing, exploratory data analysis, and predictive modeling.

---

## Key Projects & Tasks

### 1. Iris Flower Classification Project

This project focused on classifying iris flowers into different species based on sepal and petal measurements. Key learnings included:

* Data preprocessing and feature selection
* Visualizing relationships between variables
* Building and evaluating classification models

This project helped me understand the fundamentals of supervised machine learning and model evaluation.

### 2. Unemployment Analysis Project

In this project, I analyzed unemployment data to identify trends across different regions and time periods. My work involved:

* Cleaning and organizing large datasets
* Performing exploratory data analysis (EDA)
* Creating visualizations to highlight unemployment trends and patterns

This task strengthened my ability to derive meaningful insights from socio-economic data.

### 3. Car Price Prediction Project

The car price prediction project involved estimating vehicle prices based on various features such as brand, model, and specifications. I worked on:

* Handling missing values and outliers
* Encoding categorical variables
* Training regression models to predict prices

This project gave me hands-on experience with regression techniques and real-world prediction problems.
